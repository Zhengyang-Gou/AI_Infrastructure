# 09 · Research Papers

## Learning Objectives

- Read systems papers through problem, insight, method, experiments, and limitations.
- Map paper ideas to implementations, hardware constraints, and reproductions.

## Prerequisites

- Transformers, GPU/CUDA, inference metrics, and basic paper-reading skills.

## Recommended Learning Order

1. Attention Is All You Need → FlashAttention.
2. PagedAttention → Megatron-LM.
3. GPTQ → AWQ, followed by deployment comparisons.

## Key Questions

- What bottleneck does the paper solve, and do its assumptions still hold?
- Do gains come from complexity, I/O, parallelism, or engineering?

## Interview Focus

- Explain a paper in three minutes using problem → insight → method → result → limitation.
- Connect equations and figures to source code and production trade-offs.
