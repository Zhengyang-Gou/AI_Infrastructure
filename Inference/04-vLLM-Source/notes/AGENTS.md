# 笔记写作约定

- 固定场景、运行配置和全局阅读约定统一放在 `00-Reading-Setup.md`，后续正文直接使用。
- 正文沿实际调用顺序解释代码、数据和状态变化，用简明中文说明必要术语。
- 各篇直接进入当前步骤，不反复复述“本章固定为……”或枚举本次不涉及的模式。
- 删除防御性的范围提醒、反复澄清和空泛边界说明。影响当前函数行为的条件判断、因果关系和重要细节应在对应位置讲清。
- 源码节选保持连续，标明文件、类、函数和本地行号；使用示例与源码节选区分标注。
- 修改正文以现有 Markdown 文件为准，勿用旧的生成脚本覆盖后续编辑。

- 每章 README 必须包含整个推理引擎的流程图，用加粗或箭头突出当前章节。
- 每章 README 还需一张章内图，将调用路线与用途合并：每个关键调用后附一句简短说明，不再分开重复画图。
