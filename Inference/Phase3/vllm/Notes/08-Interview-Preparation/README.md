# 08 · Interview Preparation

## Learning Objectives

- Convert distributed knowledge into layered questions, structured answers, follow-up trees, and project stories.

## Prerequisites

- At least Phases 1–5 and one hands-on project.

## Recommended Learning Order

1. LLM Basics → CUDA → GPU Performance Optimization.
2. vLLM → System Design.
3. Project Presentation Template and timed mock explanations.

## Key Questions

- Can each answer progress from definition to principles, source code, experiments, and trade-offs?
- Can ambiguous system-design questions be clarified through capacity, traffic, and SLO requirements?

## Interview Focus

- Prepare a one-sentence conclusion, structured explanation, and common follow-ups for each topic.
- Include personal contribution, quantified results, and failure analysis in project answers.
